Fundamento del proyecto

¿Por qué Infrastructure as Code?

El problema clásico: "En mi máquina funciona." IaC elimina la configuración manual, hace la infraestructura reproducible, versionable y auditable.

  • 📜 provision_postgres.sh
  • 🐘 PostgreSQL instalado y configurado
  • ⚡ Runner GitHub Actions self-hosted
  • ⚠️ Levantarse siempre primero

🌐 odoo-server

  • 📍 192.168.30.10 (DMZ/vmnet2)
  • 📜 provision_debian.sh
  • 🐳 Docker + Docker Compose instalados
  • ⚡ Runner GitHub Actions self-hosted
  • 🔒 Nginx HTTPS configurado
Idempotencia garantizada: vagrant destroy -f desregistra automáticamente los runners via GitHub API REST antes de destruir las VMs. Los tokens GH_RUNNER_TOKEN_* caducan en 1h → generar justo antes de vagrant up.
vagrant up · 2 VMs en paralelo disable_nat_gateway.sh · pfSense como único GW vagrant-vmware-desktop plugin

Capa 3 IaC · CI/CD pipeline

GitHub Actions — Runners self-hosted en las propias VMs

⚙️ ci.yml — Validación

  • ✅ Valida docker-compose.yml
  • ✅ Lint de scripts Bash
  • ✅ Chequeo de variables de entorno
  • 🔁 Se dispara en cada push/PR

🚀 deploy.yml — Despliegue CD

  • 🔄 git pull en odoo-server
  • 🐳 docker compose up -d
  • 🔍 Verificación de contenedores activos
  • 🏃 Runner: odoo-server self-hosted
Ciclo completo IaC: El runner corre dentro de la VM desplegada por Vagrant → el pipeline despliega Odoo desde dentro de la propia infraestructura → ningún paso es manual.

Honestidad técnica

Limitaciones conocidas

⚠️

MACVLAN descartado

VMware host-only no permite modo promiscuo → contenedores no alcanzables desde host. Documentado en README y Vagrantfile.

⏱️

Tokens de runner caducan en 1h

GH_RUNNER_TOKEN_* deben generarse justo antes de vagrant up. Es una limitación de la API de GitHub.

🔒

Certificado TLS autofirmado

Funcional en entorno local, pero no apto para producción sin CA reconocida (Let's Encrypt con IP pública).

🖥️

pfSense configuración manual

pfSense no se gestiona con Vagrant. Existe generate_pfsense_config.sh para facilitar la config, pero el arranque es manual.
